# bazis-bg 2.5.1

Requires bazis 2.7.0. Documentation only; the code is the one of 2.5.0.

## Documentation

- The guide (`bazis/contrib/bg/AGENTS.md`, tested in `tests/test_guide.py`) and the
  manifest give the recipe of an export for the user of a request: an action of a route
  queues a `BgBaseDownload` with the id of the user and the language of the request as
  JSON arguments and `author=user` (the user reads the task and its file through the task
  route), the task restricts its rows with the `restrict_queryset` of the default route
  of the model for that user and writes its texts under `translation.override`; the API
  of `BgBaseDownload` (`get_titles`, `get_count`, `get_queryset` of objects or dicts).
- `BgRoute` and its subclasses restrict the tasks themselves: `permit.W002` of
  bazis-permit does not apply to them from bazis-permit 2.10, and they need no
  `permit_public = True` (which says the data is public).
