# bazis-bg 2.3.1

## Fixes

- Loading a zip archive made on macOS failed: since 2.3.0 the archive is searched
  recursively, which included the `__MACOSX/._<name>.xlsx` metadata files. They are skipped.
- The dynamic settings are declared with `json_schema_extra` (an extra keyword argument of
  `Field` is deprecated in Pydantic 2 and emitted a warning).
- The 2.3.0 notes on the indexes are corrected: the indexes existed in the database, the
  model no longer declared them.
