# bazis-bg 2.4.0

Requires Bazis 2.4.

## Security

- **The task route listed every background task to any client, anonymous ones included**
  (`bazis.contrib.bg.router`, `BgRoute`), with their arguments, logs, errors and files. It
  now requires authentication and shows a user only the tasks he started; staff see all
  tasks (tasks started by the scheduler have no author and are visible to staff only).

## Tools and AI agents

- The package ships `AGENTS.md` (tasks, the scheduler and handler processes, periodic
  tasks, exports and imports, cleanup and the rules) and `bazis_manifest.toml` for tools
  and AI agents (see `docs/agents.md` of Bazis).
